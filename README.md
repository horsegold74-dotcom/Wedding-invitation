# دعوة زفاف مايكل & رحيل ✞ Michael & Raheel Wedding Invitation

- **العروسان:** مايكل & رحيل (`Michael & Raheel`)
- **التاريخ:** الاثنين **23 / 11 / 2026**
- **الموعد:** الساعة **9:00 صباحاً** (`9:00 AM`)
- **المكان:** **كنيسة السيدة العذراء مريم — بورسعيد** (`St. Mary's Coptic Orthodox Church, Port Said`)
- **الموقع على خرائط جوجل:** [افتح الموقع في Google Maps](https://maps.app.goo.gl/Dx5ufvGqsqt8ftdJ8?g_st=ic)

## المميزات التفاعلية
1. **ظرف ثلاثي الأبعاد بنقش زهور بارز وختم شمعي (`M & R`)** يفتح بانسيابية مع إضاءة ذهبية دافئة وموسيقى كمان رومانسية.
2. **كروت خربشة التاريخ التفاعلية (`Scratch to Reveal Date`)** للكشف عن تاريخ الزفاف (`23` • `November / نوفمبر` • `2026`).
3. **بطاقة الدعوة المسيحية الرسمية وآية الإكليل المقدس** (*«فَإِذًا لَيْسَا بَعْدُ اثْنَيْنِ بَلْ جَسَدٌ وَاحِدٌ» — متى ١٩: ٦*).
4. **الخط الزمني لبرنامج الإكليل (`Wedding Timeline`)** من الساعة `8:30 صباحاً` حتى `11:00 صباحاً`.
5. **عداد تنازلي حي (`Live Countdown`)** حتى صباح يوم `23/11/2026` الساعة `9:00 صباحاً` مع إمكانية الإضافة لتقويم Google أو تقويم الهاتف (`.ics`).
6. **خريطة تفاعلية ورابط مباشر** لكنيسة السيدة العذراء مريم ببورسعيد.
7. **نموذج تأكيد الحضور (`RSVP`) وسجل التهاني والمباركات** ودعم كامل للغتين العربية والإنجليزية (`AR / EN`).
